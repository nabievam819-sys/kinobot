🎬 KinoBot — Telegram Movie Bot
KinoBot — это Telegram-бот, который помогает пользователям находить фильмы по уникальному коду, просматривать популярные фильмы и выбирать кино для просмотра.
Возможности
/start — запуск бота.
/help — список команд и инструкция.
/top — список популярных фильмов.
/find <код> — поиск фильма по уникальному коду.
/random — случайный фильм.
/genres — просмотр жанров.
/save <код> — добавление фильма в избранное.
/favorites — просмотр избранных фильмов.
/rate <код> <оценка> — оценка фильма.
Поиск фильма простым вводом его кода.
Удобное меню с кнопками.
Ответы на обычные сообщения пользователя.
Технологии
Python
Aiogram
Python-dotenv
Установка и запуск
Скачайте проект.
Установите зависимости:
pip install -r requirements.txt
Создайте файл .env и добавьте токен Telegram:
BOT_TOKEN=your_telegram_bot_token
Запустите бота:
python bot.py
